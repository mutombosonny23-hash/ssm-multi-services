# SSM Multi Services — Premium Dashboard

Application web responsive de démonstration pour la gestion de réservations aériennes et le suivi de commissions.

## Démarrer en local

```bash
npm install
npm run dev
```

Pour construire la version production :

```bash
npm run build
```

## Inclus

- Tableau de bord premium en français avec la marque SSM Multi Services
- Indicateurs, graphique de ventes et résumé des commissions
- Tableau filtrable de réservations et export CSV
- Ajout de réservation de démonstration
- Navigation latérale responsive

Les vols, commandes et chiffres affichés sont des données de démonstration. La mise en production avec ventes réelles demande un fournisseur de réservation (GDS/agrégateur), des identifiants API, un accord commercial de commission, un backend sécurisé et un prestataire de paiement. Le logo affiché dans cette maquette est une représentation typographique; le fichier original pourra être fourni ultérieurement.
